# Интеграции

## ЮKassa и чек

Платёж создаётся сервером через `POST /v3/payments` с уникальным `Idempotence-Key`, redirect-подтверждением и товарными позициями чека. Webhook не принимается на доверии: API повторно получает объект платежа у ЮKassa, сверяет сумму и только затем переводит заказ в `PAID` и списывает резерв.

Основные официальные документы:

- https://yookassa.ru/developers/payment-acceptance/getting-started/quick-start
- https://yookassa.ru/developers/using-api/interaction-format
- https://yookassa.ru/developers/payment-acceptance/getting-started/payment-process
- https://yookassa.ru/developers/api

`YOOKASSA_VAT_CODE` нельзя выбирать разработчику: код должен соответствовать реальной ставке, товару, налоговому режиму и настройкам кассы/договора. Его подтверждают бухгалтер и кассовый провайдер.

## СДЭК

СДЭК скрыт на checkout, пока `CDEK_ENABLED=false`. При включении сервер получает OAuth-токен, рассчитывает тариф через API v2 и подписывает котировку на 15 минут. Цена связана с точным составом корзины и кодом города, поэтому клиент не может подменить стоимость.

До production нужно проверить тестовую и боевую среду, доступные тарифы, договорный город отправления, ПВЗ, создание накладной, трекинг, печать ярлыка и фактические сроки.

## Telegram

Outbox хранится в PostgreSQL. Воркер атомарно захватывает задачи через `FOR UPDATE SKIP LOCKED`, восстанавливает зависшие блокировки и делает до пяти попыток с экспоненциальной задержкой. При отсутствии ключей уведомление получает статус `SKIPPED`. ПДн в сообщение не включаются по умолчанию.

## Маркировка

GTIN, ТН ВЭД и ОКПД2 находятся в варианте товара. Полные коды маркировки шифруются AES-256-GCM, а уникальность проверяется по SHA-256. После оплаты коды резервируются для выбытия; подтверждение фактического ввода/выбытия и идентификатор документа записываются через админку.

Боевой обмен с ГИС МТ требует договора, усиленной электронной подписи, идентификаторов участника и точного товарного процесса владельца. До их получения автоматическая отправка наружу намеренно не имитируется.
